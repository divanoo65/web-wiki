# 长周期应用开发的工具链（Harness）设计

### 执行摘要
Anthropic 的研究人员通过对长周期自主编程代理（Autonomous Coding Agents）的深入实验，提出了一套旨在突破模型性能瓶颈的工程架构。该研究指出，传统的单代理或简单的任务分解方法在处理复杂应用开发时，往往会因上下文窗口限制引发“上下文焦虑”或逻辑连贯性丧失。通过引入“上下文重置（Context Reset）”机制与“三代理架构”，研究团队成功实现了在多小时自主编程会话中构建完整全栈应用的目标。

### 核心要点
在长周期任务中，单纯依赖上下文压缩（Compaction）往往无法解决模型因接近上下文极限而产生的“上下文焦虑”，即模型倾向于过早结束任务以规避潜在的遗忘风险。Anthropic 的研究表明，通过强制性的上下文重置，配合结构化的状态交接（Handoff Artifacts），可以为代理提供“干净的石板”，从而显著提升任务执行的连贯性。

此外，该研究引入了受生成对抗网络（GAN）启发的 [[三代理架构]]，即由规划者（Planner）、生成者（Generator）和评估者（Evaluator）组成的协作系统。评估者的引入至关重要，它将主观的质量判断转化为可量化的评估标准，确保了代码生成不仅在逻辑上正确，且在设计审美与可用性上达到生产级要求。这种方法论超越了社区中常见的 [[Ralph Wiggum 方法]]，通过更精细的编排，解决了复杂任务中代理容易“脱轨”的顽疾。

尽管这种架构增加了编排复杂度和 Token 开销，但它为构建能够独立完成复杂软件工程任务的 AI 系统提供了可行的路径。通过将任务分解为可处理的块，并利用结构化制品（Artifacts）在不同会话间传递状态，开发者能够构建出具备高度可靠性的长周期应用开发工具链。
