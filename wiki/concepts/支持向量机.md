# 支持向量机 (Support Vector Machine, SVM)

### 概念定义
支持向量机（Support Vector Machine, SVM）是一种经典的监督学习算法，由Vladimir Vapnik与Corinna Cortes于1995年正式提出。其核心思想是在特征空间中寻找一个最优超平面，使得不同类别的样本点到该超平面的间隔（Margin）最大化。与传统的经验风险最小化不同，SVM基于结构风险最小化原则，通过仅依赖于少数处于分类边界附近的“支持向量”来定义决策边界，从而在处理复杂分类问题时展现出极强的泛化能力。该算法不仅能够有效解决线性可分问题，通过引入核函数（Kernel Trick），还能将低维空间中线性不可分的数据映射到高维特征空间，从而实现非线性分类，是机器学习领域处理小样本、高维数据分类任务的基石之一。

### 技术细节
1. **最大间隔原则**：SVM的目标是找到一个超平面 $w \cdot x + b = 0$，使得所有样本点到该平面的最小距离最大化。
2. **支持向量**：在训练过程中，只有位于间隔边界上的样本点（即支持向量）对确定超平面起决定性作用，其余样本点对模型参数无影响。
3. **核技巧（Kernel Trick）**：当数据在原始空间线性不可分时，SVM利用核函数（如高斯核RBF、多项式核等）计算样本在高维空间中的内积，避免了显式进行高维映射带来的计算灾难。
4. **对偶问题**：通过拉格朗日乘子法将原始优化问题转化为对偶问题，使得求解过程仅依赖于样本间的内积，进一步提升了计算效率。

### 应用场景
- **文本分类**：由于文本数据通常具有高维稀疏特征，SVM在垃圾邮件过滤、情感分析等任务中表现稳健。
- **生物信息学**：用于蛋白质结构分类、基因表达数据分析等需要处理高维特征的医学研究。
- **图像识别**：在深度学习普及前，SVM常用于手写数字识别及简单的物体分类任务。
- **金融预测**：利用其良好的泛化能力进行信用评分及市场趋势的二分类预测。
