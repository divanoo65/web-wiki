# 端到端测试

### 概念定义
端到端测试（End-to-End Testing，简称 E2E 测试）是一种软件测试方法，旨在从用户的视角验证整个应用程序的流程是否按预期运行。与单元测试或集成测试不同，E2E 测试不关注代码的各个独立模块，而是模拟真实的用户操作场景，检查系统各组件（包括前端、后端、数据库、外部 API 及 AI 模型）之间的交互是否协同工作。在长期运行代理（Long-running Agents）的语境下，端到端测试尤为关键，因为它不仅要验证单次交互的正确性，还要确保代理在跨越多个上下文窗口、经历多次会话中断后，依然能够保持任务的连贯性，并最终产出符合预期的交付物。这种测试能够有效暴露代理在状态持久化、上下文压缩及任务规划方面的潜在缺陷。

### 技术细节
在构建长期运行代理的测试框架时，端到端测试通常涉及以下技术实现：
1. **环境模拟与初始化**：利用“初始化代理”设置测试环境，确保每次测试运行在一致的初始状态下。
2. **状态验证点**：在代理执行任务的各个阶段设置检查点，验证“编码代理”是否留下了清晰的中间产物，以及这些产物是否能被后续会话正确读取。
3. **自动化交互**：集成如 [[Puppeteer]] 等工具，模拟真实的用户输入或系统触发事件，观察代理在长时间跨度下的行为表现。
4. **增量进展评估**：通过对比测试前后的系统状态，量化代理在每个会话中取得的 [[增量进展]]，确保其在处理复杂任务时不会陷入循环或丢失目标。

### 应用场景
- **复杂任务验证**：当代理需要执行长达数小时甚至数天的编码任务时，通过 E2E 测试验证其在多次上下文切换后的任务完整性。
- **回归测试**：在更新 [[Claude Agent SDK]] 或调整压缩策略后，运行端到端测试以确保代理的长期规划能力未受影响。
- **故障排查**：当代理在长期运行中出现逻辑偏差时，通过回放端到端测试流程，定位是在哪一个会话环节丢失了关键上下文。
