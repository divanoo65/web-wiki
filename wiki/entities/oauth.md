# OAuth

OAuth（Open Authorization）是一种广泛使用的开放标准授权协议，允许用户授权第三方应用访问其存储在其他服务提供商上的信息，而无需将用户名和密码提供给第三方。在现代软件架构中，OAuth 是实现安全授权的核心机制，它通过令牌（Token）机制代替了直接的凭据共享，极大地降低了安全风险。

在本视频所讨论的托管智能体架构中，OAuth 扮演了至关重要的安全角色。为了确保智能体在执行任务时的安全性，系统采用了严格的凭据隔离策略。对于自定义工具的调用，系统支持通过 [[MCP]]（Model Context Protocol）进行集成，并将相关的 OAuth 令牌存储在受保护的安全保险库中。当 Claude 需要调用外部服务时，它不会直接接触这些凭据，而是通过一个专用的代理进行操作。该代理负责从保险库中安全地获取与当前会话关联的 OAuth 令牌，并代表智能体完成对外部服务的调用。这种设计模式确保了框架本身永远不会获知或暴露任何敏感的身份验证凭据，从而在利用外部工具能力的同时，最大程度地保障了系统的安全性。

此外，这种处理方式与 [[Git]] 凭据的管理逻辑形成了互补，共同构成了托管智能体在处理外部交互时的安全基石。
