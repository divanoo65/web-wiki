# Git

Git 是一个广泛使用的分布式版本控制系统，在现代软件开发流程中扮演着核心角色。它允许开发者追踪代码变更、协同工作并管理项目的不同版本。在托管智能体（Managed Agents）的架构设计中，Git 不仅仅是一个简单的代码仓库管理工具，更被整合进安全沙箱机制中，以解决智能体在执行代码操作时可能面临的安全风险。

### 在本视频中的角色

在报告所描述的智能体框架中，Git 的集成方式体现了“安全隔离”的设计原则。为了防止智能体在执行任务时接触到敏感的访问令牌（Tokens），系统采取了特定的隔离策略：

1.  **沙箱初始化克隆**：在沙箱环境初始化阶段，系统使用特定于存储库的访问令牌来克隆 Git 仓库。
2.  **凭据隔离**：一旦仓库被克隆并连接到本地的 Git 远程仓库，后续所有的 `push` 和 `pull` 操作均在沙箱内部执行。
3.  **智能体解耦**：通过这种设计，智能体本身无需处理任何访问令牌或凭据，从而有效避免了攻击者通过劫持智能体来获取不受限制的会话权限。

这种架构确保了 Git 操作的安全性，使得智能体能够高效地进行代码协作，同时将敏感的身份验证信息完全排除在智能体的直接访问范围之外。
