# MCP (Model Context Protocol)

MCP，全称为 Model Context Protocol，是一种旨在标准化 AI 模型与外部工具、数据源之间交互的协议。在复杂的托管智能体架构中，MCP 的核心价值在于提供了一种解耦且安全的机制，使得 AI 模型（如 Claude）能够调用外部服务，而无需直接接触敏感的身份验证凭据。

在实际应用场景中，MCP 充当了模型与外部工具之间的中间层。当 Claude 需要执行特定任务时，它会通过一个专用的代理来调用 MCP 工具。该代理负责处理与会话关联的令牌，并从安全的保险库中获取相应的凭据，从而完成对外部服务的调用。这种设计模式确保了框架本身永远不会获知任何凭据信息，极大地增强了系统的安全性，防止了令牌在沙箱环境中的意外泄露。通过这种方式，MCP 不仅简化了工具集成的复杂性，还为构建更安全、更模块化的智能体系统提供了坚实的基础。

## 在本视频中的角色

在托管智能体架构中，MCP 是实现自定义工具安全调用的关键组件。它与安全保险库（Vault）配合使用，通过专用代理机制，将 Claude 的工具调用请求与敏感的 [[OAuth]] 令牌进行隔离。这种架构设计确保了智能体在执行任务时，能够利用外部工具的功能，同时保持凭据的完全不可见性，从而有效规避了安全风险。
